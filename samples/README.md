# Sample documents

Six made-up documents to try Hush without using your own files. Every person, company, address and number in them is invented. Email addresses use reserved example domains, IP addresses come from the ranges reserved for documentation, and card numbers are public test numbers. The ID, IBAN and VAT numbers follow the real Belgian formats and checksums so that Hush recognises them, but they belong to no one.

**Download all six:** [hush-samples.zip](https://microcargodecrypt-gif.github.io/Hush/samples/hush-samples.zip)

## How to try them

1. Download the zip above and unzip it, or download a single file.
2. Open [Hush](https://microcargodecrypt-gif.github.io/Hush/) (or your downloaded `Hush.html`).
3. Pick a level. **Very high** shows every data type Hush knows; **Low** only replaces names and street addresses.
4. Drop the files on the page and click **Anonymize files**.
5. Compare the original and anonymized text in the preview, and open the downloaded copies.

Running the same files at different levels is the quickest way to see what each level adds.

## Reporting a missed detection

If Hush misses something in these files, or in a file of your own, please open a [missed detection issue](https://github.com/microcargodecrypt-gif/Hush/issues/new/choose). Write a made-up example in the same format rather than pasting real data.
